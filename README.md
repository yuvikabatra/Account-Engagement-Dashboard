# Account-Engagement-Dashboard
Interactive Account Engagement Dashboard built using Tableau to analyze customer activity, engagement patterns, and business insights.
This project presents an interactive Account Engagement Dashboard built using Tableau. The dashboard helps analyze customer interactions across multiple companies by tracking engagement metrics such as page views, web visits, and form submissions.
The main objective of this project is to:
1-Analyze customer engagement behavior
2-Identify high-performing companies and contacts
3-Track activity trends over time
4-Support data-driven marketing decisions
Tools & Technologies-
1-Tableau
2-Data Visualization
3-Business Intelligence
